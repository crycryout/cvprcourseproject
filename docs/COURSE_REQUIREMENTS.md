## 不要误用其他作业规则

第 7 页“近 5 年、CCF A/B、封面信息等”针对 **academic paper reading report**。第 8 页的 project report 没有重复列出这些限制。仍应选高质量、可核实的参考文献，但不能把 reading report 的规则或其他课程的要求伪称为本项目硬性规则。

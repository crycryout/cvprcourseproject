# Published evidence: protocol v2

The completed experiment contains 300 serving cases, 12 independent 4,000-image quality evaluations, six Torch profiles and separate native Nsight captures. Read [report.pdf](report.pdf) or [the English report](../docs/REPORT.md) first. D0 did not outperform tuned F0: the paired mean goodput difference is −14.375 requests/s across 36 shared settings.

1. **Delivery and accounting:** [delivery.json](delivery.json) records case counts, failed attempts, the freeze identity and the budget snapshot; [resource_ledger.json](resource_ledger.json) preserves metered GPU leases and the separate conservative initial reserve.
2. **Formal serving:** [summary.csv](summary.csv) contains one row per completed case; [paired_comparisons.csv](paired_comparisons.csv) matches shared traces. [stage_summary.csv](stage_summary.csv) records per-run stage medians and completed-batch occupancy, with original request CSV hashes. Small [evidence files](evidence) link each run's manifest and metrics. Rejected, late, failed and unfinished requests remain in the SLO denominator.
3. **Vision quality:** [quality.csv](quality.csv) covers eager/graph/compile × buckets 1/2/4/8, each on all 4,000 held-out images; [quality_gate_v2.json](quality_gate_v2.json) binds its hash and identities. [Detection examples and source licenses](detections/README.md) use calibration images and a visualization-only score threshold of 0.7; AP uses threshold zero.
4. **Mechanism evidence:** [profile_overlap.json](profile_overlap.json), `profile_{E1,P0,C0}{,_low}.json`, [forward_microbench.csv](forward_microbench.csv) and [nsight_v2.json](nsight_v2.json) have separate profiling or GPU-resident timing scopes. Copy/kernel overlap is a fraction of summed copy durations, not request wall time. The native counters describe one actual selected kernel instance. [Figures](figures) include seed means/ranges, execution and scheduler controls, detections and the correlated timeline.
5. **Frozen inputs and environment:** [frozen_v2.json](frozen_v2.json) records pre-held-out calibration, policy parameters, model/data/source hashes and the common rate grid. [environment_timing_v2.json](environment_timing_v2.json) identifies the actual full H800; [hardware_scope_incident_v2.json](hardware_scope_incident_v2.json) explains excluded MIG work. Supporting compatibility, stress, pilot and service-table records are retained alongside them.

Each main policy has 36 settings (three arrival processes × four rates × three seeds); A0 has only 12 high-load controls. Completed-request latency and stage summaries must be read with completion ratios. Even the lowest common rate exceeds calibrated serial E1 capacity, so this grid has no unsaturated E1 point. Raw COCO data, model weights, request CSVs and full profiler binaries remain outside public Git, with hashes retained here.

From the repository root, after installing the pinned dependencies, run `python scripts/verify_results.py`. This checks the published evidence without a GPU, dataset or model download. Full experimental reproduction is documented in [README.md](../README.md).
